# Mode simulator

`mode-simulator.html` is a browser mock-up of the clock's display modes and
buttons, following `docs/firmware-features.md`. It's published as a private
artifact: https://claude.ai/artifact/K5uUMTvEVcBH4A4nDqh95f

The file is page content only (no `<html>`/`<head>` wrapper); the artifact host
adds that. To open it locally, wrap it in a minimal HTML document first.
