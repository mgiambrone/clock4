# Simulators and layouts

- `mode-simulator.html`: browser mock-up of the clock's display modes and
  buttons, following `docs/firmware-features.md`. Published as a private
  artifact: https://claude.ai/artifact/K5uUMTvEVcBH4A4nDqh95f
- `breadboard.html`: hole-by-hole breadboard layout of the 4-digit test build.
  Generated by `breadboard_gen.py` (with `breadboard_template.html`), which also
  checks that no hole is used twice and that the breadboard strips produce
  exactly the intended connections. Regenerate with
  `python3 sim/breadboard_gen.py`. Published at
  https://claude.ai/artifact/GLDbDQUUoFAuTjSyAdmsn2

The `.html` files are page content only (no `<html>`/`<head>` wrapper); the
artifact host adds that. To open one locally, wrap it in a minimal HTML
document first.
